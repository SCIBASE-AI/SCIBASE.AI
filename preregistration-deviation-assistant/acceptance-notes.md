# Acceptance Notes

This slice is intentionally narrow so it does not duplicate the existing broad research assistant suite, reproducibility intelligence, protocol trace, citation context, figure consistency, negative results, benchmark leakage, rebuttal, gap replication, grant-fit, study limitations, supplement readiness, conflict disclosure, retraction sentinel, or prompt-safety submissions.

## Reviewer Value

- Catches outcome switching before AI review describes findings as confirmatory.
- Separates prospectively amended deviations from post-hoc changes.
- Flags statistical model drift and missing multiple-testing correction.
- Detects omitted exclusion criteria and post-hoc exclusions.
- Forces unregistered subgroup findings into exploratory language.

## Local Verification

Expected commands:

```bash
npm run check
npm test
npm run demo
```

The generated reports can be reviewed without external services.
