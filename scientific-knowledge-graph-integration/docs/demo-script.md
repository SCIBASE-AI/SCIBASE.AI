# Demo Script

1. Run `npm test` to verify extraction, graph construction, navigation filters, schema.org export, and recommendations.
2. Run `npm run snapshot` and inspect `docs/demo/dashboard-snapshot.json` for a static review artifact.
3. Run `npm run demo:gif` to regenerate `docs/demo/scientific-knowledge-graph-demo.gif`.
4. Run `npm start` and open `http://localhost:4177`.
5. Confirm the dashboard shows node, edge, and entity-type counts.
6. Search for `CRISPR` and verify the navigation result includes the CRISPR concept and related biomedical objects.
7. Inspect the CRISPR entity page for citation reach, domain coverage, usage contexts, and relationships.
8. Inspect the recommendation cards; they explain why each entity is relevant to recent project activity.
