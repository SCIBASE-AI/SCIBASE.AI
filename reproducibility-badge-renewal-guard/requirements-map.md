# Requirements Map

| Issue #15 Requirement | Implementation |
| --- | --- |
| Reputation scoring | Computes transparent reputation deltas for renewed, held, expired, and revoked badges |
| Reproducibility badge | Renews, holds, expires, or revokes badges based on independent rerun evidence |
| Peer validation | Requires independent verifier identities and flags self-verification |
| Leaderboards and badge system | Emits leaderboard hold decisions so unsafe badge deltas are not published |
| Transparent metrics | Reports pass rate, verifier count, drift blockers, warnings, and audit digests |
| Review history and project timelines | Produces reviewer tasks and Markdown packets for reputation moderators |
| Abuse-resistant reputation | Blocks retracted work, artifact drift, low pass rate, and open appeal cases |
