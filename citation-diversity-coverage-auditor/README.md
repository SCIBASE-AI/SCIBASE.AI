# Citation Diversity Coverage Auditor

A self-contained AI-assisted research tools slice for evaluating citation recommendations before they are inserted into a manuscript. It focuses on the citation-tool portion of issue #13 by checking whether a candidate bibliography covers the manuscript's claims without over-concentrating on one venue, region, year range, access model, method, or population.

The module is deterministic and dependency-free. It uses synthetic data only, so it can be reviewed without API keys or private research artifacts.

## What It Checks

- Claim coverage across manuscript domains, methods, populations, and cited-for purposes.
- Citation recency balance, including recent work and older seminal anchors.
- Open-access availability for collaborators, reviewers, and funders.
- Venue and regional concentration risk.
- Method and population mismatch against the manuscript's claims.
- Risk flags such as retraction, expression of concern, or weak relevance.
- Replacement candidates for missing or risky citation slots.

## Usage

```bash
node citation-diversity-coverage-auditor/test.js
node citation-diversity-coverage-auditor/demo.js
```

The demo writes:

- `reports/audit.json`
- `reports/reviewer-packet.md`
- `reports/coverage-summary.svg`

The PR also includes a short demo video at `reports/demo.mp4`.

## Maintainer-Friendly Notes

- No external services, credentials, packages, or network calls.
- All fixtures are synthetic and small enough to inspect quickly.
- The score is explainable: each finding includes evidence and concrete reviewer actions.
- The output can be used as a guardrail for citation recommendations generated by an AI citation tool.
