# Demo Script

1. Start the suite with `npm start`.
2. Open `http://localhost:4318`.
3. Show the challenge readiness, package score, arbitration score, and final payout pool.
4. Open `/api/challenge` to inspect posting requirements, rubric, timeline, prize, and IP policy.
5. Open `/api/submission` to inspect the private workspace, manifest, team routing, and audit log.
6. Open `/api/arbitration` to inspect reviewer coverage, deliverable checklist, feedback loop, and award recommendation.
7. Open `/api/payouts` to inspect escrow status, milestone pool, team payout routing, and payout-linked IP transfer.
