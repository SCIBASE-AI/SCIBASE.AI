# Requirements Map

Issue #19 asks for enterprise tooling: admin dashboards, compliance tracking, API/webhook integrations, export pipelines, and institutional oversight.

| Requirement area | Coverage in this slice |
| --- | --- |
| Admin dashboard governance | Produces admin metrics for blocked, expired, and warning-state exceptions. |
| Compliance tracking | Enforces DPA, funder, security, data-steward approvals, expiry, and compensating controls. |
| API and webhooks | Emits deterministic webhook event bases for policy exception findings. |
| Enterprise accountability | Blocks exceptions without an active owner. |
| Export and integration safety | Reviews exceptions for restricted-data exports, schema grace periods, compute vendors, and connectors. |
