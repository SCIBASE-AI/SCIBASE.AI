# Scientific Data & Code Hosting (Issue #14)

This milestone provides auditable foundation artifacts for data/code hosting:

- Storage + artifact schema and lifecycle states
- Metadata contract (JSON-LD / DataCite / schema.org fields)
- Upload/versioning API contract
- Executable environment + run-job contract
- Implementation phases and acceptance checklist

Intended as a mergeable base to unblock incremental backend/UI implementation.
