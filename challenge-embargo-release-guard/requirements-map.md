# Requirements Map

| Issue #18 capability | Guard coverage |
| --- | --- |
| Public vs. private challenges | Holds public release while embargoes, private challenge redaction, or visibility evidence are incomplete. |
| NDA support for sensitive topics | Requires sponsor and solver release approvals before public naming or artifact exposure. |
| Submission package builder | Evaluates release artifacts for checksum, license, visibility, and redaction readiness. |
| Version control and audit logs | Emits deterministic reviewer digest and JSON packet for release audit trails. |
| IP management options | Blocks release while patent and publication holds remain unresolved. |
| Open-source submissions | Requires public artifacts to carry license and checksum evidence before publication. |
| Reward trust | Prevents sponsors or solvers from exposing results before legal and consent gates clear. |

## Non-overlap

This slice does not duplicate intake compliance, review scoring, payout readiness, data-room access, clarification freeze, award transparency, benchmark leakage, cancellation/no-award, submission license, human-subjects compliance, or solver withdrawal continuity. It covers the release boundary after an award packet exists and before challenge artifacts become public.
