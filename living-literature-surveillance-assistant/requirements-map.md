# Requirements Map

| Issue #16 Requirement | Implementation |
| --- | --- |
| Auto peer-review reports | Produces claim-level findings, blockers, warnings, and reviewer tasks for updated literature |
| Reproducibility checks | Tracks replication events and whether reusable artifacts are available |
| Research gap discovery | Converts negative/null results and extension papers into research-gap signals |
| Evidence-linked assistant output | Every update action links to claims, evidence ids, and literature event ids |
| Personalized opportunity feeds | Emits update queues and gap opportunities that can feed assistant dashboards |
| Safe AI assistant release | Blocks reports when cited evidence is retracted or high-strength contradictory evidence appears |
| Reviewable demos | Generates JSON, Markdown, SVG, and MP4 artifacts with deterministic audit digests |
