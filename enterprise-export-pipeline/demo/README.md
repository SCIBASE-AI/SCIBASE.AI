# Demo

`export-pipeline-demo.mp4` is a short reviewer demo for issue #19. It summarizes the local API flow:

1. Start the API with `PORT=4349 npm start`.
2. Inspect all supported enterprise export targets.
3. Build a Zenodo FAIR research object package.
4. Verify NIH funder compliance evidence.
5. Inspect a signed journal-submission webhook event.

The same flow is reproducible with the smoke commands in the module README.
